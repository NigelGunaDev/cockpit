# Remembered native conversations

Press leader then `o` for the inventory. Actual connection attempts to a recognized
Claude/Codex/Pi process can register exact native identity. Discovery/highlighting
alone does not. Unknown identities stay unregistered with an explanation. To link
an existing conversation explicitly, press `l`, select its agent and enter its
absolute native JSONL path. Enter reviews; a separate Enter confirms.

Inside the inventory, `r` remembers/revalidates, `f` forgets without stopping the
agent, `t` explicitly retries recovery, `c` reviews Close, `u` refreshes, and Escape
cancels. Close shows terminal and conversation identity and requires a separate
Enter. Removing a tile or detaching retains remembered intent. Task completion
and native process exit do not imply Forget.

Opening Cockpit queues enabled missing conversations in the selected socket/project
scope. The bundled helper rechecks the saved repository/worktree generation, branch,
native file/ID, socket and current terminal identity. A changed root or occupied name
is refused rather than replaced. Recovery uses exact native resume arguments and
submits no prompt. Successful attachments start read-only; native-file-open evidence
is separate from trust/authentication and model readiness.

The helper is embedded in the Rust executable and runs through `node` only when
needed. It finds agent executables using the PATH captured by Cockpit, preserving
native state-root selection. No shell alias, terminal keystroke replay or project
configuration is used as a launch definition. Short registry transactions do not
span process startup. Per-entry locks serialize recovery and Close; tmux receipts
reconcile uncertain launches without blindly spawning another process.

Explicit Close first disables saved intent, then stops only the exact verified
single-pane, unshared original agent session. A refused Close remains forgotten.
Use the terminal to inspect/exit an unconfirmed agent yourself. Native history,
Git files and worktrees remain. A closed saved tile may remain disconnected until
removed or another terminal is selected; it must never follow a replacement target.

Plain directories support terminal navigation. Automatic native recovery currently
requires a Git-backed saved workspace and branch; generic shell process restoration
and arbitrary command replay are not implemented. Missing Node/agent executables,
unavailable native files, changed repository evidence and stale/ambiguous ownership
produce visible per-entry failures. Forget stays durable across ordinary reconnects.
